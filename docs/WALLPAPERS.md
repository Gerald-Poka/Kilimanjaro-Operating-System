# Wallpaper collection

The source collection has eleven independent KDE wallpaper packages under
`overlay/usr/share/wallpapers/`. The default sunset image and five existing alternate
packages are preserved. The website uses optimized WebP copies generated by
`cd website && npm run assets`.

## Five additions — September 2026

Generated with the built-in image-generation tool, one call per scene, at the
project owner's request. These are AI-generated landscape illustrations, not
documentary photographs or proof of geographic accuracy. No external stock
images or third-party logos were supplied as generation inputs.

The generated images were 1672×941 pixels. Their OS copies were mechanically
resized and center-cropped to 3840×2160 for consistent KDE packaging; this is
upscaled output, not native 4K detail. Website copies are optimized separately.
The new package metadata offers these assets under CC-BY-SA-4.0, to the extent
copyright or other licensable rights apply. Existing assets retain their metadata.

## Generation prompt set

Shared brief: one original premium Kilimanjaro OS desktop wallpaper; wide 16:9,
3840×2160 composition; recognizable broad snow-capped Kibo dome; cinematic
painterly digital landscape, layered forms and natural textures; quiet sky and
dark foreground for desktop icons. Single full-bleed landscape, no people,
buildings, logos, watermark or collage. No text except the requested inscription.

1. **Moonlight:** moonlit Mount Kilimanjaro, rolling dark savanna foothills,
   thin silver cloud ribbons, restrained stars and a small moon; navy, teal
   and silver snow highlights.
2. **Forest Mist:** broad Kibo dome through a lush Tanzanian montane forest
   opening; mist over emerald foothills, delicate morning light, cool teal
   atmosphere and warm snow highlights.
3. **Sea of Clouds:** Kibo above a sweeping sea of soft clouds, viewed from a
   distant elevated foothill; silver snow, turquoise and pale gold dawn horizon,
   deep navy ridges; no pointed Alpine peaks.
4. **Amber Highlands:** broad snowy summit over amber/copper highland grasses;
   late-afternoon light after rain, clearing blue-grey storm clouds, teal valleys
   and flowing foreground contours; natural volcanic mountain proportions.
5. **Violet Twilight:** broad snowy Kibo dome, violet twilight, rose horizon,
   midnight-blue foothills, restrained stars, atmospheric clouds and dark acacias.
   Include exactly “Poka Machande” once, as a very small hand-engraved inscription
   on a dark foreground rock near the bottom right, charcoal-on-slate, integrated
   into the rock texture, about 5% of image width, discoverable on close inspection.
   Spell P-o-k-a M-a-c-h-a-n-d-e; not a large title, banner or bright overlay.

## Build status

These additions are in source and the website gallery/hero rotation. Existing
ISO and Debian package artifacts have not been rebuilt for this artwork change.
Use a new project package version when rebuilding: do not overwrite an already
distributed version with different payload bytes.
